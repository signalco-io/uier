# Help with uier

Start at [uier.io](https://uier.io) or [open the app](https://uier.io/app).

| You need | Start here |
| --- | --- |
| Install the review toolbar | [Embedding guide](packages/toolbar/README.md#embedding) |
| Understand projects and feedback | [Review workflow](docs/review-workflow.md) |
| Invite reviewers or manage access | [Teams and access](docs/teams-and-access.md) |
| Connect a coding tool | [Coding tool access (MCP)](docs/mcp.md) |
| Connect another service | [Integration guides](https://uier.io/integrations) |
| Run or contribute to the code | [Local setup](README.md#run-locally) and [contributing](CONTRIBUTING.md) |
| Check the service | [Status](https://uier.io/status) |

For account or setup help, email [contact@signalco.io](mailto:contact@signalco.io). Include the
page address and what happened. Keep credentials and private feedback out of public issues.

Report a reproducible bug or suggest a feature in [GitHub issues](https://github.com/signalco-io/uier/issues/new/choose).
For a vulnerability, follow the [security policy](SECURITY.md) and email
[security@signalco.io](mailto:security@signalco.io) privately.

Privacy requests go to [gdpr@signalco.io](mailto:gdpr@signalco.io). See the
[privacy policy](https://uier.io/legal/privacy-policy) for how uier handles data.

A [signalco](https://signalco.io) project.
